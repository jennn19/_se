# 任務中心 Pro

`03` 的「今日待辦」進階版。原本只有單一每日清單，這個版本加入多專案、優先度、子任務、重複任務、搜尋篩選、完成統計與資料匯入匯出，仍然維持純前端、免安裝、免後端。

直接用瀏覽器開啟 `index.html` 就能使用。

## 相對 03 的升級

| 項目 | 03 今日待辦 | 08 任務中心 Pro |
| --- | --- | --- |
| 清單 | 只有當天一份 | 多專案＋智慧清單 |
| 任務欄位 | 文字、完成狀態 | 到期日、優先度、標籤、備註、子任務 |
| 重複任務 | 無 | 每天／每週／每月自動產生下一次 |
| 找任務 | 無 | 全文搜尋、狀態／優先度／標籤篩選 |
| 排序 | 固定 | 自訂拖曳、到期日、優先度、建立時間 |
| 統計 | 當日進度條 | 今日完成、待完成、完成率、連續天數、14 天圖表 |
| 資料 | 每日分開儲存 | 單一版本化資料，可匯出／匯入 JSON |
| 誤刪 | 無法復原 | 刪除與清除後可復原 |
| 主題 | 跟隨系統 | 自動／淺色／深色手動切換 |

## 功能

- 多專案管理：新增、重新命名、刪除專案；刪除時任務會移到其他專案。
- 智慧清單：
  - 今天：今天到期與已逾期的未完成任務。
  - 未來 7 天：接下來一週到期的任務。
  - 全部任務、已完成。
- 任務細節：到期日、優先度（高／中／低）、標籤、備註、子任務。
- 重複任務：完成後自動建立下一次，支援每天、每週、每月。
- 搜尋與篩選：全文搜尋（含備註、標籤、子任務）、完成狀態、優先度、標籤。
- 排序與拖曳：自訂順序可直接拖曳調整。
- 完成統計：今日完成數、待完成數、逾期數、完成率、連續完成天數、近 14 天完成量圖表。
- 資料安全：刪除任務或清除已完成後，可在提示中按「復原」。
- 匯出／匯入：備份成 JSON，換電腦或換瀏覽器也能帶走資料。
- 主題切換：自動跟隨系統、淺色、深色。
- 自動匯入 03 資料：第一次開啟時，會把同一瀏覽器中的 `todos:YYYY-MM-DD` 待辦事項匯入「收件匣」。

## 使用方式

直接用瀏覽器開啟 `index.html`，不需要安裝任何東西。

```text
08/
├── index.html   # 頁面結構
├── styles.css   # 版面、主題與響應式樣式
├── app.js       # 所有互動邏輯與資料處理
└── README.md
```

也可以把整個 `08/` 上傳到 GitHub Pages、Netlify、Cloudflare Pages、Vercel 等靜態網站空間，取得公開網址分享。

## 鍵盤快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `N` | 新增任務 |
| `/` | 搜尋任務 |
| `Esc` | 清除搜尋或關閉對話框 |

在沒有輸入框聚焦、也沒有開啟對話框時才會觸發 `N` 與 `/`。

## 資料儲存

- 使用瀏覽器 `localStorage`，主要 key 為 `taskflow:data:v2`。
- 資料只存在開啟網站的那個瀏覽器裡，不會上傳到任何伺服器。
- 清除瀏覽器資料或更換瀏覽器後，資料不會保留，建議定期使用「匯出資料」備份。
- 03 的舊資料不會被刪除；08 第一次開啟且尚未有 `taskflow:data:v2` 時，會自動讀取 `todos:*` 並匯入。若兩者部署在不同網域，瀏覽器無法互通，需改用匯出／匯入。

資料大致長這樣：

```json
{
  "version": 2,
  "lists": [{ "id": "inbox", "name": "收件匣", "color": "#2f6f4f" }],
  "tasks": [
    {
      "id": "t_xxx",
      "listId": "inbox",
      "title": "完成專案文件",
      "notes": "",
      "priority": 3,
      "due": "2026-11-05",
      "tags": ["工作"],
      "subtasks": [],
      "done": false,
      "createdAt": "2026-11-05T08:00:00.000Z",
      "completedAt": null,
      "repeat": "none",
      "recurOf": null
    }
  ],
  "settings": { "theme": "auto", "lastList": "inbox" }
}
```

## 技術

- HTML、CSS、原生 JavaScript
- 無框架、無外部依賴、無建置流程
- 以單一狀態物件管理畫面，重新渲染維持資料一致
- `textContent` 與匯入資料正規化，避免把使用者輸入當成 HTML 執行
