# 今日待辦

一個純前端的每日待辦事項清單，打開瀏覽器就能使用，不需要安裝或後端伺服器。

## 功能

- 新增今天的待辦事項
- 勾選完成、刪除項目
- 顯示完成進度條與完成數量
- 資料自動存在瀏覽器 `localStorage`
- 依日期分開儲存，每天自動換新的一天
- 支援淺色／深色模式

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西，也不綁定特定電腦。

```text
03/
└── index.html   # 完整的待辦事項應用程式
```

也可以把 `index.html` 複製到任何電腦、上傳到任何靜態網站空間，用瀏覽器打開就能使用。

## 讓老師或其他人也能打開

這個專案是純靜態網頁，只要放到網路上就能用網址打開，不需要你的電腦開著。

### 方法一：GitHub Pages（已附自動部署設定）

專案已包含 `.github/workflows/deploy-03.yml`，會自動把 `03/` 部署到 GitHub Pages：

1. 把專案推送到 GitHub 的 `main` 分支。
2. 到 GitHub 專案頁面 → **Settings** → **Pages**。
3. 在 **Build and deployment** 的 **Source** 選擇 **GitHub Actions**。
4. 等待 Actions 執行完成，網址會是：
   `https://<你的帳號>.github.io/<專案名稱>/`

之後只要修改並推送 `03/` 的內容，網站就會自動更新。

### 方法二：任何靜態網站空間

把 `03/` 資料夾（或單獨 `index.html`）上傳到 Netlify Drop、Cloudflare Pages、Vercel 等服務，即可取得一個公開網址分享給老師。

> 注意：待辦事項存在「開啟網站的那台電腦的瀏覽器」裡，所以每台電腦看到的清單各自獨立，不會同步。若需要跨電腦同步同一份清單，需另外串接雲端資料庫。

## 資料儲存

待辦事項儲存在瀏覽器的 `localStorage`，key 為 `todos:YYYY-MM-DD`（例如 `todos:2026-11-04`）。

- 資料只存在你自己的電腦與瀏覽器中
- 清除瀏覽器資料或更換瀏覽器後，待辦事項不會保留
- 不同日期各自獨立，不會互相影響
